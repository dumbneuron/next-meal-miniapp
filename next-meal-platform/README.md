# 下一餐本地方法后台

这是本机开发后台，不是已部署的云服务。它使用 Node.js 24 内置 SQLite，默认只监听 `127.0.0.1:8787`，数据写入本目录的 `data/`；该目录由仓库 `.gitignore` 排除。

```bash
npm start
```

首次运行时终端会显示一次性管理员初始化码。访问 `http://127.0.0.1:8787/admin`，用该码设置自己的管理员账号和至少 12 字符的密码。初始化后用账号密码登录；不要将初始化码、账号数据或数据库文件上传。

后台支持基于已有稳定、渐降、碳循环规则创建方法草稿，检查后发布或下架；小程序下次进入计划页读取公开方法目录。它不执行后台输入的任意公式代码。本地测试设备可用一次性配对码同步餐食与计划；此机制不是正式微信身份体系。

```bash
npm test
```

要连同小程序核心测试及运行中的本地服务一起做只读自检，先启动后台，再运行 `npm run check:local`。完整说明及界面截图见[仓库首页](../README.md)。
