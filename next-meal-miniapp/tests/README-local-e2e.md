# 隔离模拟器端到端测试

测试脚本会使用临时小程序副本，把本机存储键改为 `e2e_next_meal_`，并启动独立的 `127.0.0.1:8788` SQLite 测试后台。它不会向本地正式联调的 `8787` 数据库写入测试餐食。

1. 在 `next-meal-miniapp` 执行 `npm install` 和 `node scripts/prepare-local-e2e.js`，记下输出的临时项目路径。
2. 在微信开发者工具设置中启用服务端口，打开刚生成的临时项目，并通过开发者工具 CLI 为该项目开启自动化端口 `9422`。不同系统和工具安装路径不同，按本机 `cli` 命令帮助执行。
3. 确认模拟器显示临时项目的今日页后，执行 `npm run test:e2e:local`。

脚本测试初次打开、自动目标和三类计划、记餐与更正、复用和撤销、成长勋章、方法发布/下架、设备配对、断开后台后记餐及恢复同步等流程。截图保存在 `tests/e2e-artifacts/`，默认不进入仓库。

系统确认框在自动化中使用 SDK 响应替身；这些测试不能代替真机、不同屏幕尺寸和真实用户操作验收。
